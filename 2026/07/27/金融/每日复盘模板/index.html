量价关系 名词全表

上涨类

名词 含义 信号
量价齐升 价格涨 + 成交量同步放大 🟢 健康上涨
放量上涨 成交量明显放大推动价格上行 🟢 多头强势
缩量上涨 价格上涨但成交量萎缩 🔴 动能不足，警惕回落
放量滞涨 成交量放大但价格横盘/微涨 🔴 主力出货嫌疑
无量空涨 几乎无成交量的上涨 🔴 虚假拉升

下跌类

名词 含义 信号
放量下跌 价格跌 + 成交量同步放大 🔴 空头强势，恐慌抛售
缩量下跌 价格跌但成交量萎缩 🟡 抛压渐尽，可能见底
放量杀跌 成交量急剧放大暴跌 🔴 恐慌盘涌出
无量空跌 无成交量支撑的阴跌 🟡 买方消失，未到底
缩量阴跌 持续小跌 + 低成交量 🔴 钝刀割肉，难见底

突破/回踩类

名词 含义 信号
放量突破 放量突破关键压力位 🟢 有效突破
缩量突破 缩量突破压力位 🔴 假突破概率大
放量回踩 突破后放量回踩支撑 🟡 回踩确认中
缩量回踩 突破后缩量回踩支撑 🟢 健康回踩，洗盘
放量冲高 放量冲击前高 🟢 强势突破意图
缩量冲高 缩量冲击前高 🔴 双顶诱多，必回落

背离/极端类

名词 含义 信号
量价背离 价格上涨，量比下降（或反之） 🔴 趋势不可持续
天量天价 成交量创天量 + 价格创高点 🔴 顶部信号
地量地价 成交量极小 + 价格创低点 🟢 底部信号
放量不涨 大量换手但价格不涨 🔴 主力高位派发

走势定性 名词全表

趋势判断类

名词 含义
趋势反转 原有趋势结束，方向改变（需放量+均线确认）
下跌中继 下跌途中的短暂停顿，之后大概率继续跌
上涨中继 上涨途中的短暂整理，之后大概率继续涨
震荡筑底 低位反复震荡，构筑底部区域
震荡筑顶 高位反复震荡，构筑顶部区域
震荡寻底 仍在寻找底部，尚未确认支撑

单日形态类

名词 含义
单边上涨 全天价格持续上行，几乎无回调
单边下跌 全天价格持续下行，几乎无反弹
冲高回落 早盘拉升 → 午后回落，收盘低于盘中高点
探底回升 早盘急跌 → 午后反弹，收盘高于盘中低点
高位横盘 全天在相对高位窄幅震荡
低位横盘 全天在相对低位窄幅震荡
V型反转 急跌后立刻急涨，形成V字形

反弹/反抽类

名词 含义
放量反弹 成交量配合的反弹，有一定持续性
缩量反弹 量能不足的反弹（弱反弹），大概率回落
技术性反弹 超跌后的技术修复，非基本面驱动
死猫跳 下跌趋势中的一次短暂反弹，之后继续新低
无量反弹 没有成交量的反弹（等同于缩量反弹，更弱）

突破/破位类

名词 含义
放量突破 放量站上关键压力位，有效突破
放量破位 放量跌破关键支撑位，有效破位
缩量破位 缩量跌破支撑位，可能是假破位

诱多/诱空类

名词 含义
诱多 制造假突破吸引散户追买，随后反手出货
诱空 制造假破位吓散户割肉，随后拉升
脉冲式诱多 瞬间放量拉升 → 量比迅速回落，典型的拉高出货
双顶诱多 缩量冲前高不过，形成双顶后回落

加速/衰竭类

名词 含义
加速上涨 涨速加快，斜率变陡（主升浪或赶顶）
加速下跌 跌速加快，斜率变陡（主跌浪或赶底）
涨势衰竭 上涨动能减弱，量价背离
跌势衰竭 下跌动能减弱，量缩+跌幅收窄

盘口特征 常见表述

名词 含义
买盘断层 买1到买5之间出现0股挂单，下方无承接
卖盘堆积 卖1到卖5堆积大量挂单，上方抛压极重
大单托底 买盘有巨量挂单，主力有意护盘
大单压盘 卖盘有巨量挂单，主力有意压价
买盘衰退 大买单逐笔减少，做多力量减弱
空头定价 卖方挂单远大于买方，空头掌握主动权
脉冲放量 量比瞬间飙升后快速回落，一次性买盘
尾盘偷袭 最后5-10分钟突然放量拉升或砸盘
缩量横盘 成交量极低，价格窄幅波动（垃圾时间）

复盘规则

1. 执行力

  • 昨晚复盘制定的交易计划是什么？
  • 买入标的、买入条件、仓位上限如何制定？
  • 是否遵循计划？如果是临时起意，理由是否充分？
  • 对比：计划 vs 实际（用表格对照）

2. 胜率环境

  • 今日大盘（上证/创业板）成交量如何？
  • 涨跌家数比如何？
  • 今日的赚钱效应属于：极好 / 一般 / 极差
  • 板块环境（游戏板块自身表现）如何？

3. 核心账户解剖

🔴 止损单（亏损交易）—— 重点严查

  • 交易标的：_________
  • 买入逻辑：（突破前高 / 回踩均线 / 消息刺激 / 其他）
  • 止损执行：到达预设止损位时，果断一刀切 / 下移了止损位 / 扛单？
  • 如果重来：回到买点那一刻，还愿意买吗？（不愿 = 冲动交易；愿意但亏 = 模式内亏损，可原谅）

🟢 止盈单（盈利交易）—— 利润回撤检查

  • 交易标的：_________
  • 卖点时机：卖出后，股价是继续大涨（卖飞）还是冲高回落（卖对）？
  • 卖飞分析：没拿住 / 达到了既定止盈目标？（达目标止盈，卖飞不可惜；没拿住需反思分时抗压能力）

⚪ 中性T单

  • 交易标的：_________
  • 值得做 / 不值得做？
  • 理由：_________

4. 心态

  • 盘前： 精力状态、是否有外部干扰
  • 盘中： 是否因浮亏/浮盈改变计划？是否出现”扳本”冲动？
  • 盘后： 今日操作满意度(1-10)；最大情绪波动时刻及原因
